Подписка

Получить список серверов из собственной подписки, без нового VPN-движка.

Проверить HTTPS-подписку

ПРЕДПРОСМОТР

Введите личную ссылку HTTPS: FreeNet прочитает подписку и покажет серверы, подготовленные как штатные Xray outbounds. Ничего не меняется на роутере.

Предпросмотр не сохраняет ссылку. После входа по HTTPS можно сохранить и применить подписку: Xray сам проверит конфигурацию, а XKeen штатно перезапустит службу. При ошибке попытка изменения отменяется. VPN/HTTPS-трафик после применения требует отдельной проверки.

Выбирается существующий balancer, на который уже ссылается routing. FreeNet не изменяет ISP/DNS/DIRECT/VPN.
НЕ НАСТРОЕНО

Найденные серверы: 0

НЕ ПРИМЕНЕНО
i

Применение доступно только в защищённой HTTPS-панели и при отсутствии прежнего контроллера FreeNet 0.8. FreeNet изменяет только собственный фрагмент Xray; пользовательские файлы XKeen/Xray не переписывает. Статус «применено» не означает подтверждённый клиентский VPN-маршрут.

Как добавить FreeNet на экран iPhone?

После включения защищённого браузерного доступа к готовой 0.9: откройте FreeNet в Safari, нажмите «Поделиться» → «На экран Домой» → «Добавить». Запуск будет в standalone-режиме без обычной панели Safari. Пока этот preview доступен только на loopback роутера и не предназначен для iPhone.
