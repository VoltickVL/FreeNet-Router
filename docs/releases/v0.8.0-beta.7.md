# FreeNet Router v0.8.0-beta.7 — согласованный список ручного VPN

## Что изменилось

Исправлен подтверждённый на Beta6 сценарий: сервер показан в окне выбора, но ручное подключение завершается до изменения конфигов сообщением «выбранного VPN нет в защищённом списке этой подписки» и `NOT_APPLIED`.

Ранее отображение доверяло отдельному безопасному JSON-каталогу, а применение проверяло профиль по защищённой сохранённой подписке. Эти данные могли разойтись после обновления кеша или версии парсера. Теперь отображаемый ручной список сверяется с тем же локальным source-bound каталогом, который использует admission подключения. При расхождении ID/адреса либо отсутствии display cache список строится из безопасных полей защищённого каталога. Для этого не нужны повторная загрузка подписки или сканирование RTT.

В браузер передаются только ID, название, страна, адрес и порт. Исходные VLESS-строки и credentials остаются на роутере. Проверки принадлежности подписке, прав доступа, допустимого формата, точного endpoint, snapshot и контролируемого применения не снимаются. Повреждённый или отсутствующий защищённый источник не становится разрешением на переключение.

## Что проверено

Изолированный PR #1164 прошёл Router CI и три Browser CI. Регрессии охватывают старый display ID, изменившийся endpoint, отсутствующий и совпадающий display cache, отсутствие сетевых вызовов при локальном чтении, разрешение каждого показанного профиля тем же private reader, сохранение содержимого/прав/времён файлов, отсутствие credentials в JSON и запрет чужого источника или небезопасных прав.

Изменены только чтение и согласование каталога с тестами. Механизмы Xray/AUTO, DNS, routing и updater в этом исправлении не переписаны. Исправления Beta6 — независимое обновление приложения, контролируемое ручное восстановление и загрузка версии Xray после входа — сохранены.

## Установка и фактическая приёмка

На установленной Beta6 используется штатное обновление FreeNet с явным выбором `v0.8.0-beta.7` в канале Beta. Дождаться терминального результата updater, проверить фактическую версию. Обновление приложения само по себе не снимает незавершённый VPN checkpoint и не доказывает восстановление интернета.

После установки заново открыть окно ручного выбора VPN, выбрать профиль из согласованного локального списка и отдельно подтвердить подключение. FreeNet выполняет предусмотренную проверку кандидата, snapshot, controlled apply, HTTPS acceptance и rollback. Только подтверждённое подключение позволяет принять новый baseline для AUTO VPN. Интернет устройств локальной сети проверяется отдельно.

Если обновление остановлено из-за незавершённого отката самого приложения, нет защищённого каталога или состояние core/snapshot неизвестно, не удалять checkpoint и не повторять запись вслепую. Зафиксировать точную ошибку. Старые Beta1 и произвольные исторические downgrade требуют своего проверенного пути и не считаются автоматически совместимыми.

Это экспериментальный prerelease, не Stable. Публикация и успешный CI не заменяют аппаратную приёмку маминого и рабочего роутеров. На момент подготовки выпуска VPN/LAN acceptance остаётся открытой; Stable latest и main не изменяются.
