# FreeNet Router v0.7.10 — подготовка установки OpenAI tunnel-client

## Что изменилось

### Добавлено

- В существующем разделе **«Администрирование» → «Доступ и диагностика»** появились «План установки tunnel-client» и «Установить проверенный клиент» (только после отдельного подтверждения).
- FreeNet поддерживает только официальные Linux ARM64/AMD64 ZIP релиза OpenAI **v0.0.16**; MIPS/MIPSEL и другие архитектуры — STOP.
- Перед установкой: проверка свободного места (не менее 190 МиБ), отсутствие существующего или неизвестного файла, жёстко заданный официальный URL HTTPS и скачивание SHA256SUMS, сравнение SHA256 ZIP, ограничения размера/времени, защита от опасных записей ZIP, ELF/архитектуры/динамического загрузчика, запуск кандидата `--version` с таймаутом.
- После подтверждения только проверенный бинарник `/opt/bin/freenet-tunnel-client` атомарно записывается в свободный путь без перезаписи существующего файла. Ошибки и неизвестное состояние приводят к STOP; staging-файлы удаляются. При неуспешном post-commit выполняется удаление кандидата; неизвестный rollback фиксируется отдельно.

## Важные ограничения

- **Tunnel не запускается!** Внешнее соединение с ChatGPT, OpenAI Platform tunnel ID, runtime API key, установка пользовательского MCP plugin и дальнейшая работа коннектора ещё **не завершены**.
- Установщик требует аутентифицированную браузерную сессию, явное подтверждение и проверенное TLS либо localhost. Обычный HTTP LAN и недоверенные прокси-заголовки не принимаются. Если HTTPS заканчивается на внешнем reverse proxy, настройку доверия к этому прокси нужно отдельно подтвердить — нельзя ослаблять проверку автоматически.
- Не передавать runtime API key, 15-минутный machine bearer, tunnel ID, подписки и Xray credentials в GitHub/issues/логи или чат.
- Загрузка и SHA256-проверка **не означают, что Sigstore provenance уже проверена**: подпись upstream не верифицируется этим инсталлятором и может потребовать отдельного security этапа.
- Никаких изменений VPN, DNS, routing policy, подписок или Xray/XKeen. Бинарник клиента не стартует и не открывает входящие порты.

## Проверено

- [PR #1107](https://github.com/VoltickVL/FreeNet-Router/pull/1107) — отдельное минимальное изменение, terminal CI SUCCESS 4/4: Go/HTTP/Zip/ELF/rollback contract tests, браузер, сетевые тесты и кросс-сборки. На промежуточном HEAD выявлена и исправлена синтаксическая ошибка Go, финальные проверки SUCCESS.
- Runtime acceptance на конкретном Keenetic/Netcraze **не проводилась**. Успешность загрузки upstream GitHub и ABI на реальном Entware пока не подтверждены; при ошибках установка должна остановиться без изменения VPN.

Подтверждение установки в браузере на роутере ARM64, затем отдельное безопасное управление жизненным циклом `tunnel-client`, защищённое provision/revoke runtime secret, реальные OpenAI Platform/ChatGPT permissions и пробный read-only MCP-вызов. До успешного end-to-end status показывать «ChatGPT не подключён».
