# FreeNet Router v0.8.0-beta.19

Улучшение устойчивости AUTO VPN: подтверждение повторяющихся проблем и дополнительная проверка перед сменой сервера.

## Что изменилось

- **AUTO ищет замену при устойчивой проблеме с сервисами.** Для поиска нужны повторяющиеся завершённые проверки одного и того же проблемного сервиса минимум за две минуты. Единичный сбой и незавершённая проверка не запускают подбор.
- **Меньше лишних переключений.** Если полный свежий замер показывает, что текущий VPN уже работает хорошо, AUTO прекращает поиск. Перед возможной сменой кандидат повторно проверяется, затем подтверждается, что исходная проблема текущего VPN ещё сохраняется. Восстановившееся подключение остаётся на месте.
- **Отсутствие замера не принимается за плохую скорость.** Незавершённое измерение больше не позволяет считать текущий сервер заведомо хуже и обходить обычные ограничения на переключение.
- **Сохраняются строгие требования к замене.** AUTO учитывает скорость, задержку, её разброс, стабильность загрузки и доступность сервисов. При поиске улучшения подключение не меняется до окончания сравнения; применяется именно проверенный кандидат.
- **Надёжнее сохраняется пауза между поисками.** Параллельное обновление фонового статуса не может затереть сохранённую паузу. Если состояние нельзя надёжно сохранить, новый поиск откладывается.

Аварийное восстановление при подтверждённом полном отказе VPN сохраняет отдельный алгоритм. Отображение числовой скорости и главного экрана из предыдущего выпуска сохранено.

## Проверка

Добавлены проверки повторяющихся и разовых сбоев, восстановления подключения во время поиска, неполных измерений, смены профиля, общей паузы, параллельного сохранения состояния и запрета применения при устаревших или неизвестных данных.

Выпуск публикуется после успешных проверок в GitHub Actions. Бинарные сборки формируются для ARM64, MIPS и MIPSLE. Работа на конкретном роутере проверяется после официальной установки; успешное обновление не подменяет наблюдение за реальными автоматическими переключениями.
