# FreeNet Router v0.8.0-beta.20

Исправление согласования фоновых проверок и переключения VPN.

## Что изменилось

- **Ручное переключение и AUTO VPN согласуют работу с фоновыми проверками.** Проверки, запущенные отдельным процессом планировщика, теперь используют общий допуск с веб-интерфейсом. Перед сменой сервера FreeNet дожидается окончания таких проверок и не запускает новые до завершения переключения или отката.
- **Устранена причина ложного отказа перед переключением.** На некоторых системах служебный проверочный процесс попадает в общий список Xray. Теперь штатные фоновые проверки не пересекаются с применением профиля и не мешают запуску рабочего VPN через XKeen.
- **Ошибка допуска не считается успешной проверкой.** Если общий допуск недоступен, проверка конфигурации и завершение настройки возвращают явный отказ.
- **Сохранены проверки рабочего процесса и отката.** Неизвестные или лишние процессы Xray по-прежнему останавливают изменение. Исправление не завершает чужие процессы и не отключает защиту незавершённых операций.

Алгоритм выбора качества AUTO VPN, отображение скорости и настройки маршрутизации не меняются.

## Проверка

Добавлены межпроцессные сценарии ожидания фоновой проверки, запрета новых проверок во время переключения, отмены ожидания и безопасного отказа при недоступном файле допуска. Проверяется освобождение ресурсов и сохранение допуска после завершения ожидания, пока операция ещё выполняется.

Выпуск публикуется после успешных проверок GitHub Actions и сборки для ARM64, MIPS и MIPSLE. Качество связи с конкретным сервером оценивается после установки; исправление согласования процессов само по себе не гарантирует скорость внешнего VPN-сервера.
