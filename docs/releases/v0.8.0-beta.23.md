# FreeNet Router v0.8.0-beta.23

## Что изменилось

- Исправлено ожидание остановки панели при обновлении: завершение главного потока процесса больше не считается доказательством закрытия его HTTP-сокетов.
- Обновлятор до 90 секунд ожидает освобождения ранее проверенных сокетов. При повторном ожидании того же процесса во время отката используются исходный срок и сохранённая идентичность; повторный сигнал остановки этому процессу не отправляется.
- Новый владелец порта, изменение идентичности процесса или невозможность подтвердить завершение по-прежнему останавливают операцию с сохранением защитных блокировок.

Изменение касается жизненного цикла панели при обновлении. Проверки файлов выпуска, сохранности настроек и итоговой версии приложения остаются обязательными.
