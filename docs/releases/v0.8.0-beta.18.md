# FreeNet Router v0.8.0-beta.18

Обновление измерения скорости и главного экрана VPN. Скорость остаётся видна при повторной проверке, а разовый сбой замера получает автоматическую повторную попытку.

## Что изменилось

- **Надёжнее завершается замер скорости.** После окончания загрузки проверочному процессу отведено короткое время для передачи результата приложению. Это устраняет гонку, при которой приложение могло остановить процесс одновременно с его собственным тайм-аутом и потерять уже полученные данные. Общий срок проверки остаётся ограниченным; требования к достаточному объёму данных и числу успешных потоков сохранены.
- **Последняя измеренная скорость сохраняется.** Если новая проверка не дала значения, на экране остаётся предыдущий успешный замер с его настоящим временем. Он сохраняется после обновления страницы и перезапуска приложения. Скорость другого сервера или другого профиля не переносится на текущее подключение.
- **Повторная попытка без лишних действий.** Если текущая проверка не дала скорости, интерфейс может один раз тихо повторить замер. Во время обновления значение остаётся на экране. Приложение ограничивает автоматические попытки для одного подключения, в том числе при открытии нескольких вкладок и перезагрузке страницы. Кнопка ручной проверки остаётся доступна по обычным правилам.
- **Понятный главный экран.** Для доступного подключения показывается короткий статус «VPN работает». Технические критерии выбора сервера не превращаются в предупреждение для пользователя. У скорости есть время измерения; во время проверки — короткое «Обновляем…».
- **Результаты не перемешиваются.** Запоздалый ответ предыдущей проверки не заменяет новый результат. При смене сервера или профиля старое значение убирается. Сохранённая для показа скорость не подменяет свежие данные, на которых основаны автоматический выбор и оценка доступности VPN.

## Проверка

В общий состав изменений включены проверки завершения настоящего дочернего процесса, ограничений времени, сохранения скорости и её исходного времени, неудачного последнего замера, повторной попытки и смены подключения. Проверки в браузере охватывают главный экран, сохранённое значение, поздние ответы и ограничение автоматических запросов.

Выпуск публикуется после успешных проверок общего состава изменений в GitHub CI. Сборки формируются для ARM64, MIPS и MIPSLE.

## Аппаратная приёмка

После публикации на портативном, рабочем, мамином и домашнем роутерах проверяются точная установленная версия, работа VPN, новый замер скорости, отображение результата и его сохранение после обновления страницы. Фактические результаты фиксируются в [журнале #7](https://github.com/VoltickVL/FreeNet-Router/issues/7).
