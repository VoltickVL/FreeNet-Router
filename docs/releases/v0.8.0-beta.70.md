# FreeNet Router v0.8.0-beta.70

## Что изменилось

## WORK: безопасное восстановление осиротевших диагностических Xray

После beta.69, установленной на WORK, подтверждённая изолированная Xray-проба может остаться с parent PID 1. Это блокирует restart_ready при восстановлении Split DNS, хотя production Xray продолжает работать.

[PR #1304](https://github.com/VoltickVL/FreeNet-Router/pull/1304) вводит строго авторизованную операцию POST /api/xray/probes/reconcile в Control Center, доступную только с подтверждением, без SSH-команд и без смены VPN-профиля.

Защиты:
- один проверенный production Xray, только известные isolated probes, отсутствие unknown/zombie;
- запрет при updater lock, незавершённой VPN transaction, конкурирующей FreeNet operation;
- эксклюзивная cross-process probe fence, повторный инвентарь перед операцией;
- существующий проверенный reaper: завершение **только** диагностического процесса с PPid=1, root UID, совпадающим binary inode, private конфигурацией и фиксированным PID/starttime;
- после операции обязательное подтверждение 1 production / 0 probe / 0 unknown / 0 zombie; при несоответствии STOP.

Операция **не** меняет production Xray, XKeen, VPN, DNS, маршрутизацию, подписки и credentials. Перезапуск роутера не требуется.

## Границы аппаратной приёмки

- Выход beta.70 не означает автоматическую очистку проб или восстановление Split DNS. Сначала штатный update plan/verified manifest, затем **одна** защищённая операция и terminal postcheck.
- После готовности процесса отдельно выполнить штатный Split DNS repair из beta.69: snapshot, candidate Xray validation, controlled restart, DNS TXT/MX acceptance и rollback. При FAILED/UNKNOWN — STOP.
- Клиентские UDP/TCP DNS A/AAAA/TXT/SRV/HTTPS и реальный VPN egress должны быть подтверждены на WORK перед заявлением о стабильности. Другие роутеры не трогать.
- Активная аппаратная задача [#1301](https://github.com/VoltickVL/FreeNet-Router/issues/1301), реестры [#7](https://github.com/VoltickVL/FreeNet-Router/issues/7) и [#5](https://github.com/VoltickVL/FreeNet-Router/issues/5).
