# FreeNet Router v0.8.0-beta.86

## Что изменилось

### Быстрее повторные обновления FreeNet на медленном GitHub/CDN

В прежних версиях Web Updater загружал **все компоненты релиза** с GitHub последовательно, даже если многие файлы остались побайтово теми же. На роутерах с медленным доступом к GitHub это приводило к ненужным задержкам при установке очередной beta.

В beta.86 механизм обновления использует **повторное применение уже установленных проверенных файлов**. Для каждого FreeNet-owned компонента:

1. Сначала обязательно загружается манифест `SHA256SUMS` **выбранного точного релиза**.
2. Если установленный файл — обычный читаемый файл (не symlink), его SHA-256 сравнивается с ожидаемым SHA-256.
3. При точном совпадении файл **копируется в приватный staging** и повторно проверяется по SHA-256. Жёстких ссылок на изменяемый runtime нет.
4. Если файла нет, он не подходит, имеет другой хэш, недоступен или проверка копии не прошла — остаётся прежняя ограниченная по времени загрузка с GitHub, с повторами и SHA-256.
5. После staging по-прежнему выполняются полная валидация, snapshot, controlled apply, post-apply acceptance и штатный rollback/STOP при сбое.

Состояние обновления может показывать, какие именно штатные файлы удалось безопасно взять локально. Секреты, подписки и пользовательские конфигурации в этой операции не затрагиваются.

**Ограничение:** этот механизм вступает в силу **после установки beta.86**. Первое обновление с beta.85 до beta.86 ещё выполняется старым updater. Эффективность зависит от доли неизменившихся компонентов и доступности GitHub; конкретное сокращение времени не обещается без аппаратных замеров.

### Безопасность и совместимость

Изменены исключительно `scripts/self_update.sh` и тесты обновления. **Не меняются** XKeen/Xray, VPN-профили, ISP-политики, DNS, маршрутизация, подписки, credentials и режим Xray Live Pool. Обновление FreeNet не активирует Live Pool автоматически. Механизмы release tag verification, SHA256SUMS, update lock, preservation of VPN evidence, snapshot и rollback остаются обязательными.

### Аппаратная приёмка

Management сообщил об установке beta.85 на WORK, HOME, MOM и Portable (4/4); beta.86 не устанавливалась этим циклом. Фактический статус Xray Live Pool, клиентский media QoE и успешность rollback на реальных роутерах этой функцией не подтверждены. Обычная установка остаётся через FreeNet Control Center, без ручного SSH.
