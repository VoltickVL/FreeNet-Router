# FreeNet Router v0.8.0-beta.71

## Что изменилось

### Split DNS: ограниченное подтверждение после перезапуска Xray

В beta.70 на HOME одна управляемая операция восстановления Split DNS вернула HTTP 502 с ошибкой post-apply active profile acceptance failed и ROLLBACK FAILED/UNKNOWN, хотя дальнейшие независимые read-only проверки показали работающий Split DNS, один подтверждённый Xray и отсутствие диагностических процессов. Это противоречие терминальной квитанции и последующего фактического состояния **не считается успешным откатом**.

Принятый [PR #1307](https://github.com/VoltickVL/FreeNet-Router/pull/1307) изменяет только контроль уже выполненной DNS-операции: после успешного core apply и сохранения режима XKeen, прежде чем вызывать rollback из-за первой отрицательной post-apply проверки, FreeNet может выполнить до трёх дополнительных **read-only** сетевых планов с интервалом две секунды.

Принятие возможно лишь при строгом совпадении действующей топологии: success, supported, active, mutation NONE и exact xkeen DNS/effective mode. При системной ошибке, неизвестном результате, unsupported state или устойчиво неактивном Split сохраняется прежний STOP и существующий rollback. Повторный DNS apply, restart или обход защит автоматически не выполняются.

### Что не меняется

- VPN и VLESS credentials, подписки, AutoVPN/Best Server, Xray binary и GID, ISP presets и правила маршрутизации;
- DNS generator и policy A/AAAA/TXT/MX/HTTPS, Keenetic/XKeen конфигурация до штатного аппаратного apply;
- работающий split-tunnel и поведение UDP/STUN/WebRTC; диагностика звонков WhatsApp/Telegram/FaceTime — отдельная задача после подтверждения стабильности DNS.

## Границы аппаратной приёмки

- Выпуск beta.71 и успешный CI не изменяют сами по себе работающие роутеры и не разрешают считать прежний HOME rollback FAILED/UNKNOWN восстановленным.
- На HOME после исходного HTTP 502 повторные read-only проверки показали Split ACTIVE и Xray READY, но это не замена первоначальной квитанции. До доказательного reconciliation не выполнять повторный apply, restart, reboot, SSH mutation или удаление блокировок.
- WORK beta.70 ранее подтвердил Split DNS ACTIVE и клиентские DNS A/TXT/MX/SRV/HTTPS; изолированная диагностика UDP/STUN показывает отдельный DIRECT путь, который нельзя устранять глобальной переадресацией UDP без маршрутной приёмки.
- Для любой будущей установки: официальный release CI terminal SUCCESS, tag/SHA256/assets, авторизованный FreeNet updater read-only plan READY, guarded apply и terminal postchecks; при FAIL/UNKNOWN — STOP.
