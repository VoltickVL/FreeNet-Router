## Что изменилось

### Добавлено
- В боковом меню появился новый раздел **«Администрирование»** с диагностическими инструментами, работающими прямо в браузере.
- Команда **«состояние»** показывает версию FreeNet, процесс Xray, выбранный режим DNS, наличие подписки и текущую занятость.
- Команда **«dns адрес»** проверяет разрешение публичного домена через системный DNS роутера. Например: `dns sg.api.io.mi.com`.
- Команда **«журнал»** показывает краткую сводку технической диагностики. Подробности по-прежнему доступны в разделе «Журнал».
- Команда **«помощь»** показывает список поддерживаемых действий.

### Безопасность
- Диагностические запросы требуют авторизации, имеют ограничение по времени и не меняют настройки VPN, DNS и маршрутизации.
- Команда DNS не принимает IP-адреса, локальные домены, произвольные URL и SSH-команды.
- Форма не исполняет команды оболочки роутера.

### Что важно знать
- Ответ DNS **не показывает**, через DIRECT или VPN прошёл трафик. Это только проверка системного разрешения доменного имени.
- **Подключение ChatGPT к роутеру**, наблюдение реальных соединений устройств локальной сети и встроенный SSH-терминал в этой версии **не реализованы**. Администрирование пока работает только через браузер FreeNet.
- Механика VPN, AUTO VPN, Xray/XKeen, маршрутизация, действующие настройки DNS и механизм обновления не изменялись.
- Автоматические тесты прошли; работу версии на конкретном роутере необходимо подтвердить после установки.
