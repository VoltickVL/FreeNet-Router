# FreeNet v0.8.0-beta.63

## Что изменилось

### Xray Core: устранена неоднозначная ошибка проверки версии после загрузки

- Исправление [PR #1288](https://github.com/VoltickVL/FreeNet-Router/pull/1288), terminal 4/4 PR CI SUCCESS, merge `148f9c1f1535a2ac5e746713e7eeda30b1cdd9e3`.
- При обновлении Xray FreeNet теперь отдельно ограничивает этапы: официальный каталог, проверенную загрузку и распаковку (95 с); исполнение `xray version` извлечённого кандидата (15 с); предпусковую проверку единственного доверенного Xray и резервное копирование (30 с).
- Если истёк срок загрузки, проверка версии уже не запускается с отменённым контекстом. Если запущенный кандидат вернул другую версию, не удалось исполнить бинарник либо истекло время его проверки, в квитанции сохраняются **разные безопасные reason-коды**. Прежняя неоднозначная ошибка `downloaded Xray binary does not match selected version` больше не скрывает фактический класс сбоя.
- Сохраняются обязательная официальная SHA-256 целостность архива, точное совпадение версии, строгий native process inventory (XKeen GID 0 либо FreeNet GID 11111 только при подтверждённых inode/config), атомарная замена, проверка после запуска и rollback. При неизвестном результате — STOP.
- Добавлены Go-тесты: корректная версия, реальный mismatch, ошибка исполнения, отменённый child, timeout, истёкший этап загрузки и независимый ограниченный контроль кандидата; обновлён транзакционный тест для точного reason-кода.

### Безопасное обновление на работающих роутерах

Установка **самого FreeNet beta.63** не изменяет бинарник Xray, не перезапускает XKeen/Xray и не переписывает VPN, DNS, фильтр, маршрутизацию или credentials. Следующее обновление Xray через отдельный Control Center Xray Core допускается только после успешного штатного self-update FreeNet, проверки инвентаризации и подтверждённого readiness, с резервным снимком, postcheck и rollback. Слепо повторять завершившийся FAIL нельзя.

### Аппаратная приёмка Portable — ещё открыта

На Portable до этого релиза Xray **v26.10.21** остался исправным после попытки перехода на **v26.10.31**. Историческая квитанция: `FAILED / rollback NOT_NEEDED`, ошибка классификации версии до binary swap. Beta.63 исправляет продуктовый алгоритм и диагностику, но сама по себе **не доказывает** успешную установку Xray 26.10.31 или полную клиентскую VPN/QoE-приёмку. Пилот выполняется отдельно по [Issue #1236](https://github.com/VoltickVL/FreeNet-Router/issues/1236) с фиксацией результата в [журнале #7](https://github.com/VoltickVL/FreeNet-Router/issues/7).

### Совместимость

Keenetic/Netcraze с Entware, FreeNet, XKeen 2.1, Xray. Обновление штатно выполняется через браузерный FreeNet Control Center; исправные компоненты existing stack сохраняются.
