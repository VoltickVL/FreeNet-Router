# FreeNet v0.8.0-beta.45

## Что изменилось

### AutoVPN: подтверждённые HTTPS stalls больше не теряются

[PR #1250](https://github.com/VoltickVL/FreeNet-Router/pull/1250) MERGED, 4/4 terminal PR CI SUCCESS, MERGE SHA `1fb29bc29e7b36247fcf0a00359c26a8ef085e79`.

- При `curl exit=28`, HTTP 200 и убедительной **частичной** загрузке (не менее 16 KiB, неполные 512 KiB, корректные времена и >=2 сек) watchdog учитывает факт зависшей передачи как плохой видеосегмент; раньше такой результат всегда становился UNKNOWN.
- Ошибки HTTP 403/429, другие exit status, слишком малый/неподтверждённый body, NaN/Inf, отмена наблюдения остаются UNKNOWN и не заставляют переключать рабочий VPN.
- Два отдельных наблюдения одного VPN identity, проверенная лучшая альтернатива, сравнение непосредственно перед apply, transaction snapshot, post-acceptance, rollback и запрет mutations при неопределённой Xray identity остаются обязательными.
