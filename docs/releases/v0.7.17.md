# FreeNet Router v0.7.17 — восстановление проверенного обновления

## Что изменилось

- Устранена дополнительная зависимость штатного обновления от доступности GitHub REST API на роутере. Если точные метаданные тега не удаётся получить через API, установщик проверяет метаданные из **отдельного файла GitHub Release**, присутствующего в `SHA256SUMS`, и отклоняет любые несовпадения SHA-256.
- Релиз содержит `release-metadata.json` с точным тегом, признаками `draft` и `prerelease` и русским описанием изменений. Этот файл проверяется по опубликованному `SHA256SUMS` и не принимается, если отсутствует, изменён или указывает на иной канал Stable/Beta.
- Обновляющий shell-helper сначала использует обычный DNS/HTTPS маршрут роутера. Только при сетевом сбое пробует ограниченный резервный DNS/IP; проверка TLS не отключается.
- Вместо неопределённого отказа предварительная проверка возвращает конкретный тип ошибки: GitHub API, загрузка проверенного релиза, SHA-256 или несоответствие канала. До успешного read-only плана установка не начинается.
- Добавлены тесты недоступного API, повреждённых/неуказанных в manifest метаданных, несовпадения Stable/Beta, требования явного согласия Beta и неизменности рабочих файлов до применения.

## Что не меняется

Код маршрутизации, провайдерские профили, VPN/Xray/XKeen, ключи и подписки, DNS, правила маршрутизации и автоматизация остаются без изменений. Применение по-прежнему требует точного тега, проверки SHA-256 компонентов, backup/snapshot, controlled apply, post-apply acceptance и rollback при ошибке. Unknown или failed rollback остаётся жёстким STOP.

## Установка без SSH

Для уже установленной FreeNet 0.7.15/0.7.16, у которой предыдущий helper не проходит проверку метаданных, штатное восстановление загрузит `self_update.sh` **из этого опубликованного Stable-релиза**, предварительно сверит его SHA-256 и собственный план, и только после отдельного подтверждения выполнит обновление FreeNet. Если GitHub Release не доступен с роутера или контроль целостности не подтверждён, операция остановится без изменений.

Пилот проводится на одном роутере: после установки проверить текущую версию, доступность интерфейса, фактический VPN/Xray и журнал обновления. Остальные устройства обновлять только после подтверждения пилота.
