# FreeNet Router v0.8.0-beta.25

## Что изменилось

- Добавлена **дополнительная информационная проверка ChatGPT HTTPS** в результаты «Проверить текущий VPN» и «Подобрать серверы»: запрос к публичному `https://chatgpt.com/` через тот же изолированный маршрут VPN-кандидата, без cookies, авторизации, пользовательских сообщений и чтения содержимого ответа. До 3 секунд на проверку; она выполняется параллельно с уже предусмотренными измерениями.
- Результат показывается отдельно под четырьмя метриками: «HTTPS отвечает», «HTTP-ограничение · проверить в браузере», «HTTP-ошибка сервиса» либо «не подтверждено». Ответы 401/403/405/429 не считаются отказом VPN; успешный ответ сайта сам по себе не доказывает доступность авторизованного чата.
- **Сохранены четыре обязательных QoE-сервиса**: Instagram, Telegram Web, WhatsApp Web и YouTube. ChatGPT-диагностика не участвует в их 4/4, масках, баллах, критериях пригодности серверов, AUTO VPN, failover или переключениях.
- На карточках текущего VPN и альтернатив исправлено перекрытие значения «Отклик сайтов» нативной подсказкой соседней метрики скорости. Подсказка остаётся на названии показателя; измеренное значение видно.
- Добавлены регрессионные проверки HTTP-классификации, отмены и ожидания дочерних процессов, отсутствия влияния на решение AUTO, результата в API и отображения в браузере.

**Не изменено:** работающий VPN, алгоритм AUTO VPN, DNS, маршрутизация, Xray/XKeen, GeoData, подписки и пороги качества. Этот выпуск меняет только FreeNet Control Center/его диагностику. Установка на действующем роутере проводится отдельно штатным updater с plan, резервной копией, проверками результата и отката.
