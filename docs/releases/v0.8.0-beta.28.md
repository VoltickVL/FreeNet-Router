# FreeNet Router v0.8.0-beta.28

## Что изменилось

### GeoData / GeoIP: ручное обновление больше не обрывается из-за HTTP 504

- Исправлена подтверждённая проблема Control Center: ручной запрос GeoData исполнял `xkeen -ug` внутри долгого HTTP POST. Если внешний HTTPS reverse proxy завершал запрос по тайм-ауту (HTTP 504), Go-контекст отменял дочернюю операцию, поэтому база могла остаться необновлённой, а журнал показывал обобщённый native error.
- `POST /api/settings-v3/action` с действием `geodata_update` теперь возвращает `202 Accepted` и идентификатор единственной операции. Сам XKeen выполняется независимо от жизненного цикла браузерного запроса, с ограничением по времени 12 минут.
- Добавлен защищённый авторизацией короткий `GET /api/settings-v3/geodata-operation`. Интерфейс опрашивает состояние и показывает **идёт / успешно / ошибка**, включая фиксированные безопасные причины, не запуская XKeen повторно при перезагрузке страницы или повторном нажатии.
- Если обновление уже идёт, повторный запрос не запускает вторую копию. Сохранены прежние общая lock-блокировка FreeNet/Xray, STOP при конфликте с VPN/rollback, контроль исходного состояния процесса Xray и fail-closed.
- Тайм-аут native XKeen и отмена выполнения теперь имеют отдельные фиксированные безопасные сообщения вместо общего неразличимого текста. Нативный stdout/stderr, подписки, URI, конфигурации и ключи в API/Journal не передаются.

### Проверки

- Go unit/contract tests проверяют быстрый HTTP 202, независимость процесса от отмены клиентского запроса, дедупликацию повторного запуска, конечный статус, fail-closed после перезапуска и отсутствие публикации секретов в ответе.
- Проверены короткий браузерный start/status protocol и восстановление наблюдения после обновления вкладки, без автоматической повторной mutation.
- Сохранены штатные проверки GeoData, блокировок, watchdog, Update/Recovery и Release MIPS32LE. Merge и выпуск — только после успешного terminal CI.

### Границы исправления

Этот выпуск **устраняет обрыв самого ручного запуска из-за браузерного HTTP 504** и позволяет увидеть результат реальной операции, но **не заявляет исправлением всех источников GeoIP/GeoSite**: если upstream недоступен, ошибка скачивания должна быть подтверждена отдельной штатной проверкой и исправлена отдельным циклом. Не меняются GeoData downloader XKeen, источники, существующие .dat, DNS, маршрутизация, VPN-профиль, AUTO VPN, XKeen/Xray core или конфигурации с секретами. Если XKeen не подтвердил загрузку и завершение, FreeNet не выдаёт успех.

Переключение VPN и устранение клиентских зависаний видео Telegram/Instagram — отдельные задачи. Обновление на действующем Portable выполнять штатным Update с preflight, сохранением резервной копии, проверкой точного SHA-256, версии, Xray и окончательного результата; не обходить блокировки и не применять вручную незащищённые команды.
