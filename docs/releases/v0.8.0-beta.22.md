# FreeNet Router v0.8.0-beta.22

## Что изменилось

- Исправлена точечная проверка выбранного VPN-сервера. Если провайдер меняет параметры подключения при повторной выдаче подписки, FreeNet проверяет именно запись, выбранную из защищённого локального каталога.
- Проверенный профиль сохраняется для последующего подключения без подмены новой редакцией подписки. Результат содержит источник каталога и время его обновления.
- При смене подписки, текущего сервера или фильтра во время проверки устаревший результат отклоняется. Если выбранная запись уже исчезла из каталога, панель предлагает выбрать сервер заново.

Порог качества для подключения и ограничения времени проверки сохранены. Точечная проверка сама VPN не переключает.
