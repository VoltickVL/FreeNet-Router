# FreeNet Router v0.7.8 — локальный MCP и подготовка подключения ChatGPT

## Что изменилось

### Добавлено
- **Локальный MCP adapter** в FreeNet: POST /mcp с ограниченным набором инструментов только для чтения (состояние FreeNet, здоровье компонентов, расчёт правила маршрутизации и доступность безопасного журнала). JSON-RPC/MCP и строгие схемы; реальные действия над VPN/DNS/Xray отсутствуют.
- **«Администрирование» → «Проверить подключение ChatGPT»**: FreeNet автоматически показывает архитектуру Linux/CPU, локальный MCP и статус 15-минутного разрешения. Для Linux ARM64/AMD64 отмечается только наличие официальных сборок клиента, **не доказанная готовность Entware**.
- **MIPS/MIPSEL STOP**: официального OpenAI tunnel-client под эту архитектуру нет. Подмена бинарника, публикация LAN/WAN портов, отключение localhost-ограничений и SSH-обходы не допускаются.
- Русская инструкция `docs/CHATGPT-CONNECTOR-TUNNEL-RU.md` с проверенными условиями OpenAI Platform/ChatGPT, секретами и разграничением прав.

### Безопасность
- Локальный MCP работает по отдельному краткоживущему read-only Bearer, не использует cookie браузера, ограничен loopback, не принимает shell/SSH и не отправляет полные Xray-конфигурации, подписки и секреты.
- Preflight **не запускает tunnel-client и не меняет настройки**. Статус реальной связности с ChatGPT остаётся «НЕ ПОДТВЕРЖДЕНО» до успешного end-to-end вызова.
- Результат проверки Xray маршрута — расчёт по сохранённым правилам, **не** подтверждение фактического DIRECT/VPN LAN-клиента. Для непроверенного GeoSite/GeoIP по-прежнему UNKNOWN.

### Пока не реализовано
- **Внешний Secure MCP Tunnel и установка ChatGPT plugin**. Необходимы права OpenAI Platform, tunnel ID/runtime key, подходящий запуск официального клиента либо проверенный защищённый мост для MIPS, а затем runtime acceptance. Никакие ключи нельзя публиковать в GitHub/чат.
- Managed lifecycle tunnel-client, автоматическая безопасная ротация авторизации и диагностика фактических LAN-потоков — самостоятельные этапы Roadmap #5.

### Проверки и ограничения
- Source PR #1102 (MCP) и #1104 (preflight) с terminal CI SUCCESS, включая Go/HTTP security, browser, shell и кросс-сборку.
- Релизный CI дополнительно проверяет сборки, пакет и манифест `SHA256SUMS`.
- **Рабочие роутеры этим релизом не обновлялись автоматически**. Реальная проверка FreeNet v0.7.8 на конкретном Keenetic/Netcraze и подключение ChatGPT должны фиксироваться отдельно.
- Действующие VPN, DNS, routing policy и Xray/XKeen не перенастраиваются этими изменениями.
