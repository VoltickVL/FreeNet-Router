# FreeNet Router v0.8.0-beta.82

## Что изменилось

### Теперь списки XKeen можно редактировать непосредственно из FreeNet

В **Control Center → Config Studio → Списки XKeen** вместо прежнего режима READ ONLY появился текстовый редактор трёх штатных файлов:

- `ip_exclude.lst` — IP/подсети, исключаемые из проксирования; для одиночных IP указывайте маску `/32` или `/128`.
- `port_proxying.lst` — исходящие порты, трафик которых должен перехватывать XKeen (например, 80/443).
- `port_exclude.lst` — исходящие порты, которые исключаются из проксирования.

Можно изменить существующие строки, оставить комментарии, отменить черновик или создать отсутствующий штатный список. Сохранение выполняется через **авторизованный API FreeNet**, без ручного SSH, с показом результата и проверкой, что файл действительно записан.

**Важно о портах:** эти файлы управляют **исходящим перехватом**, а не открывают входящие WAN-порты и не меняют проброс портов Keenetic. Порты проксирования и исключения портов нельзя включать одновременно: FreeNet отклоняет конфликтующие активные списки, вместо тихого приоритета одного над другим.

### Сохранение защищает работающую конфигурацию

Перед записью FreeNet сверяет SHA-256 исходного списка, проверяет допустимость имени файла и синтаксиса, не следует по symlink, отвергает слишком широкие LAN исключения (например, `192.168.0.0/16`) и опасные/некорректные строки портов. Перед заменой создаёт частную долговечную копию с `fsync`, затем выполняет атомарную запись, readback-проверку и rollback/STOP при неизвестном результате. В редакторе сохранены комментарии и порядок строк.

**Разница между сохранением и активацией:** кнопка «Сохранить список» меняет только файл на диске. Она **не перезапускает XKeen/Xray, не меняет iptables/ipset, DNS/VPN, routing policies и не объявляет новые kernel rules активными**. Интерфейс явно показывает `XKEEN_RELOAD_REQUIRED`: для реального применения сохранённого списка потребуется отдельная подтверждённая штатная операция активации XKeen. Это намеренно, чтобы не прерывать работающий интернет при редактировании.

## Что осталось без изменений

- Работающие VPN-профили, подписки, серверы, AUTO selection и QUIC Vision.
- DNS/Split DNS, ISP policies, Xray outbounds и уже загруженные kernel netfilter/ipset rules.
- Установленные XKeen/Xray и настройки роутеров: выпуск релиза в GitHub **сам по себе не устанавливает обновление на устройства**.
- Никакой WAN port-forward, TUN/full-device capture или автоматический XKeen restart не включается.
