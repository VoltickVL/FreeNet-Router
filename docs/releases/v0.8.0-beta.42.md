# FreeNet v0.8.0-beta.42

## Что изменилось

### Достоверная диагностика доступности сервисов без ложного «не работает»

На работающем Portable приложение ChatGPT открывается в браузере, хотя автоматический неавторизованный HTTP-запрос может получать `403 Forbidden`. Ответ такого типа не доказывает, что приложение или VPN не работают.

- Для четырёх фиксированных QoE-сервисов ответы `401`, `403`, `405` и `429` на ограниченные `HEAD`-проверки **больше не создают отрицательную отметку недоступности** и не дают ложный повод для AUTO VPN quality strike. Эти ответы также не засчитываются как подтверждённое «Работает».
- Превышенный лимит редиректов (`curl 47`) не считается подтверждённым отказом браузерного приложения: в этом случае ограниченная проверка не смогла дать достоверное заключение.
- Корректно подтверждённые успешные HTTP-ответы остаются положительным сигналом, а настоящий HTTP `503` и проверенные сетевые отказы сохраняются как отрицательные **QoE-сигналы**, но одиночный сервисный ответ не классифицирует весь VPN как отключённый.
- Незавершённая/ограниченная проверка не создаёт ни ложное «Работает», ни ложное «Не работает»: продукт ждёт достаточных независимых подтверждений. Защитные инварианты AUTO не ослаблены: при неполном сервисном evidence автоматическое применение не разрешается только на основании такого результата.
- Дополнительная диагностика ChatGPT по `HEAD` по-прежнему **не подтверждает** авторизацию, отправку сообщения и работу браузерного приложения. Её `403` никогда не служит основанием для VPN-отказа.

### Проверки

[PR #1245](https://github.com/VoltickVL/FreeNet-Router/pull/1245): все четыре CI-workflow завершились `SUCCESS` (Go tests, основной router CI, Routing Browser, Config Studio Browser и Production Browser). Добавлены регрессии для `401/403/405/429`, смешанного случая `403 + timeout` и неизменности обработки подтверждённого `503`/защиты от ложного global VPN outage.

### Границы релиза и аппаратная приёмка

Изменены только классификация ограниченных HTTP-ответов и её тесты. **VPN-профили, credentials, DNS, routing, основной Xray/XKeen, автоприменение и установщик не изменены.** На Portable до выпуска сохраняется рабочий профиль Франция/Париж Extra; его переключение или Xray restart не нужны для проверки этого исправления.

Отдельный P1 по Xray process inventory (`unknown-xray-process` при `xray_online=true`) не входит в этот релиз и остаётся закрыт для сетевых mutations до доказательного runtime-факта. Реальная работа ChatGPT подтверждена Management в браузере; ограниченный `HEAD` не подменяет эту приёмку. Полная клиентская HTTPS/медиа и AUTO failover acceptance остаются отдельными задачами.
