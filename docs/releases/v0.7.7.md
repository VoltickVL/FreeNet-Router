# FreeNet Router v0.7.7 — исправления Control Center

## Исправлено

- **Администрирование:** длинные результаты диагностики маршрутов, FQDN, SHA256, сообщения о локальном ChatGPT Connector и одноразовый токен больше не выходят за границы карточек. Текст переносится внутри блока, сохраняется скрытие разового секрета. Проверено браузерными тестами на ширинах **320, 375, 768 и 1440 пикселей**.
- **Config Studio — защита локальных черновиков:** результат запоздавшей фоновой загрузки больше не может сбросить состояние **STALE**, снова разрешить «Применить» или незаметно перезаписать черновик после внешнего изменения маршрутов. Заменить черновик можно только через явную кнопку «Отменить» или после подтверждённого успешного применения.
- Добавлен детерминированный браузерный тест гонки: ответ `GET /api/config-studio` специально задерживается до редактирования и внешнего изменения; подтверждается сохранность черновика, запрет Apply и корректность Reset. Ранее этот сценарий периодически давал ложную успешную проверку после повторного CI.

## Безопасность и ограничения

- **VPN, XKeen/Xray, DNS, routing policy, подписки и секреты не перенастраиваются** этим выпуском.
- Локальный диагностический read-only API и 15-минутное разрешение коннектора из v0.7.6 сохранены.
- **Реальное внешнее сопряжение с ChatGPT и Secure MCP Tunnel ещё не реализовано.** Версия не обещает фактического наблюдения трафика LAN-клиента; неизвестный результат маршрутизации остаётся `UNKNOWN`.
- Выпуск проходит Go/shell/browser/cross-build CI. **Фактическая установка и runtime acceptance на роутере требуют отдельной проверки через Control Center после обновления.**

- PR #1097 — защита Config Studio от асинхронной перезаписи черновиков.
