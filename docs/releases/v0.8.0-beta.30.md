# FreeNet Router v0.8.0-beta.30

## Что изменилось

### Быстрый каталог опубликованных Beta

- Вместо чрезмерно тяжёлого GitHub REST `/releases?per_page=100` для Beta используется официальный публичный Atom feed **опубликованных** релизов `releases.atom`, с ограничением ответа 96 КиБ, штатным 10-секундным бюджетом и компактным кешем. В списке — последние 10 опубликованных релизов; скрытые Draft не попадают в официальный feed. Stable-каталог сохраняет прежнюю обработку.
- Отдельные Stable/внешние и некорректные ссылки, неподходящие Beta-теги, испорченные даты и XML отвергаются. При ошибке/прерывании/слишком большом feed каталог не выдумывает версии, не переключается на Stable и не вносит изменений в роутер.
- Для старых Beta вне последних десяти и для нестабильной сети в окне выбора версий есть поле **«Точная Beta-версия вне списка»**. Ввод не устанавливает ничего: только запускает штатный exact plan. Без успешных metadata, `MANIFEST_VERIFIED` и проверки target нет кнопки установки.
- Release notes на компактной странице не имитируются: текст выбранного выпуска подгружается из проверенного exact plan.

### Надёжный exact-release preflight на медленном соединении

- Для Beta штатный helper сначала пытается получить компактные публичные `SHA256SUMS` и `release-metadata.json`, проверяет SHA-256 метаданных и только затем доверяет тэгу/признаку prerelease. При недоступности этого пути сохраняется ограниченный резервный запрос к точным GitHub Release metadata; **`releases/latest` для Beta не используется**.
- Проверка fail-closed: точный `tag_name`, явные булевы `draft/prerelease`, корректный JSON, совместимость и полный manifest перед любой mutation. При отказе выводится безопасная категория: transport timeout / DNS / HTTP-код / неверный или неполный JSON / mismatch tag / Beta или Stable channel / SHA256-манифест, без вывода секретов или полного stdout.
- Не меняются AUTO, VPN-правила, подписка, DNS, routing, XKeen, Xray, GeoData и логика транзакционного обновления. Snapshot, staging, acceptance и rollback действуют по прежним контрактам.

## Проверки и приёмка

- Go fixture tests: опубликованный Atom feed, смешанные Stable/Beta/чужие ссылки/даты, лимит 96 КиБ и повреждённый XML, кеш, timeout/cancellation, отказ без fallback в Stable, сохранение точного Beta-plan в UI.
- Shell regressions: Beta channel opt-in, неверные метаданные, обязательный manifest и безопасная остановка без mutation.
- Для Portable: строгое обновление по подтверждённому точному beta30, сохранение VPN/Xray, `/healthz`, `/versionz`, SHA256 MIPSLE, квитанция `SUCCESS/NOT_NEEDED`, проверка выбора Beta из браузера.

Не относится к этому PR: реальные замеры зависаний видеопотока Instagram/Telegram и ускорение длительного QoE Best Server. Это отдельные задачи Roadmap.
