## Что изменилось

### Добавлено
- В разделе **«Администрирование»** появилась read-only форма **«Диагностика маршрутизации»**: ввод домена/IP назначения, порта, TCP/UDP и необязательного IP LAN-клиента. Проверка ищет однозначные совпадения по порядку правил сохранённой конфигурации Xray и показывает ожидаемое DIRECT, VPN, BLOCK или **«Неизвестно»**.
- Диагностика сопровождается отпечатком SHA256 файла правил и явным разделением **расчётного правила** и **факта соединения**.
- Подготовлен локальный read-only диагностический API для будущего ChatGPT Connector: ограниченный набор запросов к состоянию компонентов и расчёту маршрута. Сырые журналы, подписки и конфигурации с секретами не выдаются.
- В «Администрировании» появились просмотр локального разрешения, **выдача на 15 минут** и **отзыв доступа**. Токен хранится на роутере только в виде хеша, показывается один раз, стирается с экрана через 60 секунд, при уходе из раздела и при потере авторизации.
- Выровнены верхние карточки состояния относительно основной колонки Control Center на широких экранах.

### Безопасность
- Любая диагностика правил работает без переключения VPN, изменений DNS, перезапуска Xray, SSH и произвольных команд.
- Непроверенные GeoSite/GeoIP, неизвестный Xray inbound, неоднозначные правила, баланcировщики и цепочки outbound **не получают выдуманное DIRECT/VPN**: возвращается «Неизвестно».
- Машинный диагностический API доступен только с самого устройства по loopback и с отдельным временным read-only Bearer-токеном. Есть отзыв, истечение срока, ограничения частоты и проверка приватности хранилища.
- **Выдача токена по обычному HTTP из локальной сети запрещена.** Требуется доверенное HTTPS-подключение либо локальный loopback. Порт FreeNet/SSH не нужно открывать в Интернет.

### Что ещё не готово
- **ChatGPT пока не подключается к роутеру напрямую.** Защищённый внешний MCP/relay-транспорт и полноценное сопряжение с ChatGPT разрабатываются отдельно.
- Проверка правил Xray **не является наблюдением реального LAN-трафика** и не подтверждает, что конкретный запрос Home Assistant прошёл через DIRECT или VPN. Для `geosite:xiaomi` строгая проверка установленной GeoSite-базы и фактического Xray inbound ещё не реализована.
- Локальный просмотр технического журнала в машинном API пока возвращает «недоступно», а не неочищенные события.

### Проверено
- Для включённых изменений успешно выполнены Go, shell, браузерные и кросс-платформенные CI-проверки. Один ранее существующий browser-test Config Studio проявил нестабильность и прошёл на повторе того же SHA; его стабилизация остаётся отдельной задачей.
- Установка и эксплуатация **v0.7.6 на реальном роутере ещё не подтверждены**.

### Не изменилось
- Существующие настройки VPN, Xray/XKeen, DNS и маршрутизации, активные профили, подписки и сохранённые секреты этим выпуском намеренно не перенастраиваются.
- Безопасное восстановление VPN после аварийной транзакции и внешнее сопряжение ChatGPT требуют дальнейших отдельных этапов.
