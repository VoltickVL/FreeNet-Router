# FreeNet Router v0.8.0-beta.9 — безопасность ручного переключения Xray

## Что изменилось

**Безопасная проверка завершения процесса Xray (#1170).** Исправлен механизм core-only перезапуска при ручном переключении VPN: вместо одного `kill -0` проверяется состояние исходного процесса и его идентичность по Linux procfs. Завершившийся процесс в состоянии zombie больше не считается работающим только из-за успешного `kill -0`. Если PID был повторно использован, процесс остаётся активным или непрерываемым, его состояние нельзя прочитать либо обнаружен дополнительный Xray, FreeNet прерывает применение с конкретным безопасным результатом, не убивая чужие процессы.

**Защита уже существующих настроек.** Перед применением по-прежнему создаётся защищённый checkpoint, а при ошибке выполняется контролируемый rollback. Существующий XKeen/Xray, подписка, ISP/DNS, маршрутизация и пользовательские credentials не заменяются. Смена сервера не превращается в полный произвольный restart XKeen.

## Что проверено

В CI PR #1170 на Beta HEAD `17a7620e933ba3d97f8d21998fb66ec0718afa0b` выполнены targeted тесты Linux PID lifecycle (zombie, active, D-state, reuse, UNKNOWN), транзакционного выбора VPN, источника подписки, rollback, shell syntax, Browser UI, secret-surface и кросс-сборки (ARM64/MIPS32LE/MIPS32). Финальный Actions run `39267823951` завершён **SUCCESS**. Реальный сбой Giga ранее имел код `old-core-still-running` и завершался успешным откатом; фактический процессный state старого ядра тогда не был зафиксирован.

## Как проверить на переносном Giga

Это **Beta prerelease**, не Stable. Обновлять только FreeNet через штатный verified update с резервной копией и exact target `v0.8.0-beta.9`. При pending checkpoint или UNKNOWN/FAILED rollback — STOP. После успешного обновления сначала прочитать `transaction-doctor` и действующий VPN; затем выполнить **один** выбранный вручную сервер через guarded UI и проверить terminal success, Xray, клиентский интернет и сохранение DNS/routing. Если операция сообщит live/D/reused/UNKNOWN, больше не переключать до диагностики.

**Ограничения:** кодовый фикс не доказывает, что старый PID был zombie, и не заменяет hardware acceptance. AUTO VPN, планировщик GeoData и синхронизация active outbound с подпиской требуют отдельных runtime-проверок/циклов. Домашний, мамин и рабочий роутеры этим выпуском автоматически не изменяются.
