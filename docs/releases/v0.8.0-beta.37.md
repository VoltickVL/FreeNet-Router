# FreeNet Router v0.8.0-beta.37

## Что изменилось

### Xray обновляется самим FreeNet — без XKeen UI

FreeNet Control Center самостоятельно скачивает официальный MIPS32LE Xray через DIRECT и сверяет SHA-256, архитектуру и точную версию. **XKeen UI, его HTTP API и XKeen CLI для обновления не нужны.**

1. FreeNet определяет текущий работающий Xray, его исполняемый файл, группу 11111, рабочий каталог конфигурации и уникальный PID.
2. Скачивает и проверяет новый официальный архив, затем создаёт резервную копию старого ядра.
3. Атомарно заменяет бинарник и самостоятельно, через Go-процесс FreeNet, перезапускает Xray с необходимыми XRAY_LOCATION_CONFDIR, XRAY_LOCATION_ASSET, GID 11111 и отдельной сессией.
4. Контролирует версию, соответствие фактического исполняемого файла, единственность процесса и устойчивость запуска. Не запускает повторные долгие xray run -test во время установки.
5. При сбое восстанавливает старый бинарник через тот же собственный механизм запуска. Если восстановление не подтверждено, сохраняет STOP и резервную копию.

Обычное обновление не зависит от фоновых диагностических probe-слотов. Дополнительная read-only диагностика доступна в развёрнутом разделе, не является обязательной для обновления.

## Старый STOP после бета36

Отдельное авторизованное действие FreeNet «Подтвердить восстановленный Xray» проверяет работающую версию, GID, inode бинарника и отсутствие незавершённой VPN-транзакции. Устаревший STOP снимается только после проверки, исходный ROLLBACK FAILED остаётся в истории; никакие Xray/DNS/routing-файлы этим действием не меняются.

## Ограничения

Это исправление только механизма обновления Xray. Ранее зарегистрированные HTTPS body stalls (#1225), Extra switching (#1227) и возможные расхождения DNS/filter-engine остаются отдельными задачами. Рабочие VPN-профили, секреты, DNS и routing policy не изменяются.

Сначала терминальный PR CI и релиз beta.37, затем аппаратная приёмка **только Portable**. XKeen UI может быть установлен на существующем роутере, но FreeNet не обращается к нему для обновления. Будущая FreeNet-only установка не должна требовать XKeen UI.
