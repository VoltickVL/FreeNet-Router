# FreeNet Router v0.8.0-beta.8 — единое оформление Control Center и надёжный вход

## Что изменилось

**Единый дизайн без конкурирующих статических CSS-слоёв (#1142).** Теперь canonical Control Center использует один `web/design-system.css` до инициализации модулей. Сохранены согласованная тёмная палитра, карточки, навигация и оформление из прежних рабочих версий. Удалены устаревшие вставки постоянных CSS из JS и Go, конкурирующие значения ширины и 399 перекрытых деклараций. Старый `layout_coherence.go` удалён. Динамическое состояние и расположение выпадающих окон остаются частью нормальной логики интерфейса, но не создают дополнительных статических тем.

**Читаемость и адаптивность.** Убрано принудительное уменьшение текста до 7–9 px в зависимости от высоты браузера. На узких экранах подписи, рекомендации и кнопки VPN переносятся внутри карточек, а не обрезаются; доступная вертикальная прокрутка сохраняет обычный размер шрифтов. Согласованы заголовок текущего VPN, флаг, бейдж подключения, кнопки и карточки результатов.

**Целостная загрузка без «фантомного» старого Обзора.** Критические модули UI поступают в одном HTML соответствующей сборки; готовность означает инициализацию Overview, topbar, selector, Settings, Routing и Journal, а не только наличие логотипа. При неполной загрузке старый интерфейс не показывается как якобы готовый: есть ограниченное ожидание, явная ошибка, повторное открытие и независимый Recovery. Этот защитный экран не меняет VPN, DNS или маршруты.

**Долгий вход (#1166).** Режим «Оставаться в системе 30 дней» в обычном Control Center и Recovery; сохранение сессии при перезапуске FreeNet без сохранения пароля в браузере. Временный сбой сети не должен ошибочно сбрасывать авторизацию; настоящий выход/смена пароля по-прежнему закрывают доступ. Для прежней короткой сессии после обновления может понадобиться один повторный вход.

**Состояния действий (#1167).** Фоновое чтение не включает запрещённое применение в редакторе, карточка версии FreeNet не появляется пустой.

Исправления Beta7 ручного VPN, Beta6 контролируемого восстановления, AUTO VPN и независимого обновления приложения сохранены. Этот релиз не переписывает runtime backend Xray/XKeen, правила DNS или routing, подписку и пользовательские профили.

## Обновление и ограничения

Это **Beta prerelease, не Stable**. В FreeNet выбрать канал Beta и **точный тег `v0.8.0-beta.8`**, проверить план и штатно применить только обновление приложения FreeNet. Не переустанавливать рабочие Entware, XKeen или Xray, не сбрасывать незавершённую VPN-транзакцию, не заменять конфиги. При неизвестном состоянии updater/rollback — STOP и диагностика без повторной записи. Recovery должен использовать точный тег с явным согласием на Beta; пустая цель означает актуальный Stable и для этого перехода недопустима.

Порядок развертывания: **сначала мамин роутер** с проверкой успешного self-update, версии, состояния приложения и уже работающего VPN/AUTO/LAN; только затем — рабочий, затем домашний. Успешный CI и публикация релиза не доказывают интернет на клиентских устройствах; аппаратная приёмка проводится отдельно. Main и Stable `v0.7.18` этим выпуском не изменяются.
