# FreeNet Router v0.8.0-beta.69

## Что изменилось

### Split DNS: корректная обработка TXT, MX, HTTPS/SVCB и других DNS-записей

- [PR #1302](https://github.com/VoltickVL/FreeNet-Router/pull/1302) MERGED `e9a3cc978441a2f6286bdf7acba8432eeffa2783`, 4/4 terminal PR CI SUCCESS. Исправлен подтверждённый WORK дефект: прежний Xray `dns-out` обрабатывал A/AAAA, но мог отвечать пустым `NOERROR` на TXT/MX и другие типы DNS-записей; трафик iMac дополнительно перехватывался штатным Keenetic DNS resolver из-за `native-intercept=on`.
- Генератор Split DNS теперь оставляет A/AAAA на текущей доменной политике Xray и направляет остальные типы записей к указанному DNS по `dialerProxy=vless-reality`, без необоснованного перехода на DIRECT. До применения строго подтверждается единственный реальный VLESS outbound, валидируется Xray candidate, а после controlled restart проверяются непустые TXT и MX через Xray TCP/53 до `ndmc save`. При отказе срабатывает штатный rollback.
- Read-only network plan распознаёт устаревший `dns-out` как `split-nonip-incomplete`, а не как полностью исправный Split DNS. Добавлены негативные и JSONC тесты, проверка failure/rollback.
- Использован проверенный принцип DNS-over-VLESS из [Xkeen-UI](https://github.com/umarcheh001/Xkeen-UI/blob/main/docs/dns-over-vless.md), но без прямого копирования чужого кода. [XKeen Panel](https://github.com/Dearonski/xkeen-panel) изучен отдельно для прокси-проверок, сохранения `sockopt` и последующей эволюции failover; его пул серверов в этот выпуск не входит.

### Безопасная идентификация штатного XKeen 2.1

- Сохраняется исправление [PR #1298](https://github.com/VoltickVL/FreeNet-Router/pull/1298), включённое с beta.68: проверка идентичности Xray принимает GID 0 **только** при подтверждении единственного owned процесса, inode установленного бинарника, точного каталога конфигурации и отсутствия diagnostic probe. Неподтверждённые GID и неизвестные процессы остаются STOP. Никакого принудительного изменения GID.

## Границы, безопасность и аппаратная проверка

- Релиз сам по себе не меняет DNS, VPN, credentials, ISP policy или работающий Xray на роутере: установка приложения отдельно выполняется только по guarded update plan.
- Для WORK beta.67 установлен исходный read-only факт: Split `active=false`, `native-intercept=on`, `dns-routing=split-intercept`, Xray GID 0 (owned), единственный production Xray, checkpoint отсутствует. Fresh HTTPS VLESS PASS, но active outbound stale/mismatched — это отдельный остаток и не является доказанным клиентским VPN.
- **Аппаратный gate:** terminal Release CI, SHA256 проверка официальных артефактов, штатный browser update plan/backup/rollback, затем read-only DNS plan, gated Split repair с checkpoint/snapshot, post-apply TXT/MX/A/AAAA/HTTPS client DNS и подтверждением фактического клиентского VPN egress. ROLLBACK FAILED/UNKNOWN = STOP; никаких ручных быстрых правок DNS или бездоказательного restart.
- Связанные задачи: [#1227](https://github.com/VoltickVL/FreeNet-Router/issues/1227), [#1281](https://github.com/VoltickVL/FreeNet-Router/issues/1281), [Roadmap #5](https://github.com/VoltickVL/FreeNet-Router/issues/5), [Journal #7](https://github.com/VoltickVL/FreeNet-Router/issues/7). HOME/MOM/PORTABLE этим выпуском не меняются.
