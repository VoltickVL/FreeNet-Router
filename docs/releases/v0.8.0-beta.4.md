# FreeNet Router v0.8.0-beta.4 — аварийное восстановление ручного VPN и доставка через проверенный bridge

## Что изменилось

- **Ручной выбор Extra восстановлен как аварийное действие.** Если AUTO VPN оставил защищённый `PENDING` checkpoint и живое состояние Xray проверяемо, FreeNet допускает явный ручной выбор сервера в отдельной транзакции, не очищая прежний snapshot заранее.
- **Два защищённых снимка и конечная проверка:** второй snapshot фиксирует реальные текущие VPN-файлы; кандидат проходит Xray validation, core-only restart и HTTPS. После доказанного успеха новый профиль становится базовым для продолжающего работать AUTO VPN. При ошибке восстанавливается состояние перед попыткой, исходный checkpoint и STOP сохраняются. DNS, ISP policy, XKeen/netfilter не перенастраиваются.
- **Read-only Journal doctor и диагностика:** выводятся статусы before/live `out/profile/filter`, Xray core и STOP decision без секретов. В журнал попадают раздельные PRIMARY ERROR, rollback files/core/VPN; generic HTTPS и частичная QoE не приравниваются к доказанному VPN_DOWN.
- **Новый Browser Recovery умеет точные Beta-релизы.** После установки этой версии восстановление проверяет target, manifest и SHA-256, сохраняет checkpoint и применяет только FreeNet-owned assets; не запускает смену VPN.
- **Одноразовый verified legacy bridge исправлен для Beta:** принимает только канонический тег `vX.Y.Z-beta.N`, позволяет предварительный read-only `plan`, требует `FREENET_BRIDGE_BETA_ACK=yes` для `apply`, проверяет SHA-256 загруженного целевого `self_update.sh` и передаёт ему явный Beta opt-in. Тесты проверяют отсутствие скрытого Beta apply, корректный target и malformed tags.

## Что важно для уже установленной v0.8.0-beta.1

Старый Browser Recovery Beta1 **не умеет выбрать Beta4** и при кнопке восстановления updater обращается к latest Stable. Обычное обновление Beta1 может блокироваться `MUTATION_BLOCKED=yes` из-за старого VPN checkpoint. Поэтому **не нажимайте старый Recovery в ожидании обновления до Beta4**: для первого перехода необходим одноразовый проверенный delivery bridge через отдельно согласованный доступ к роутеру. Нельзя удалять VPN checkpoint или перезапускать Xray вручную.

После обновления FreeNet автоматически не меняет VPN. Нужны фактическая read-only диагностика, явный ручной выбор Extra, проверка HTTPS через Xray и LAN-клиента, подтверждение передачи выбранного сервера AUTO VPN. Если исходное состояние противоречиво или непроверяемо, FreeNet должен остановиться с конкретной причиной.

## История выпуска и ограничения

Попытка публикации Beta3 была остановлена CI **до выпуска** из-за заголовка release notes. Исправление задокументировано и прошло PR CI; новая публикация штатно выпускается под `v0.8.0-beta.4`, без изменения или повторного использования прежнего тега.

Это экспериментальный prerelease, не Stable. CI и fault-injection тесты подтверждают исходный код, но пока не подтверждают восстановление интернета на реальном MOM. Отдельный GitHub Release содержит три Entware архитектуры, `SHA256SUMS` и точный неизменяемый набор ассетов; Stable latest не заменяется.
