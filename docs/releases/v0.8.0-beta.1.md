# FreeNet Router v0.8.0-beta.1 — предварительная версия

## Что изменилось

- В основе — рабочая ветка `v0.7.4`, с выборочным переносом нужных исправлений интерфейса до 0.7.10, без раздела «Администрирование».
- BlancVPN: согласованное получение каталога (DIRECT → через действующий VPN → защищённая локальная копия) без замены подписки и секретов.
- Ручное переключение сервера не зависит от обязательного долгого RTT/plan-сканирования. Выбранный профиль принимается через проверяемый Xray apply, post-apply HTTPS и защиту от неподтверждённого отката. При успешном выборе AUTO VPN остаётся включённым и продолжает свою работу.
- AUTO VPN: подавление повторных тяжёлых аварийных сканирований, статусная фиксация каждого терминального результата, оценка качества с порогами 300/420/650 мс и обязательными повторными подтверждениями. Реальная недоступность HTTPS обрабатывается отдельно от колебаний пинга.
- Технический журнал: датированная история значимых событий за последние 720 часов, ограничение заполнения USB-накопителя, явное обозначение пропусков, потоковый авторизованный архив JSONL/GZIP из браузера.
- Beta и Stable строго разделены: Stable остается каналом по умолчанию; Beta показывается только по отдельному запросу, требует точного тега, явного подтверждения и SHA-256. Публикация Beta не меняет GitHub `latest`.

## Ограничения Beta

**Предварительная сборка для ограниченных испытаний, не проверенный Stable.** Сборка и автоматические тесты не заменяют приёмку на реальном Keenetic/Netcraze с Entware, XKeen и Xray. Не подтверждены целевые показатели простоя клиента при аварии, безопасный manual→AUTO cutover на каждом оборудовании и полный 30-дневный цикл хранения на USB. Отдельный заранее подготовленный резерв BlancVPN в этот выпуск **не добавлялся**: его необходимость и безопасность будут проверяться на фактическом оборудовании.

**Не устанавливать автоматически на действующие стабильные роутеры.** Рабочие VPN, DNS, routing, credentials и действующий Xray должны оставаться нетронутыми до явного выбора Beta. При неподтверждённом rollback или противоречивом runtime — STOP. Обновление ядра Xray не входит в Beta.

## Способ распространения

Релиз распространяется как GitHub **prerelease** с проверяемым `SHA256SUMS` и бинарниками ARM64/MIPSLE. Обычный установщик и штатное `latest` по-прежнему ведут на Stable. Для ограниченного пилота требуется явное указание точного тега `v0.8.0-beta.1` и opt-in; из уже установленной Beta обновление/возврат доступен через выбор соответствующего канала. Старые установки 0.7.4 не начинают автоматически видеть или устанавливать Beta.

После публикации следующий этап — аккуратная аппаратная приёмка на заранее выбранном тестовом роутере с резервной копией, измерением HTTPS через LAN и проверяемым откатом. До неё обещание нулевого простоя некорректно.
