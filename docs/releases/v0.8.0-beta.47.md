# FreeNet v0.8.0-beta.47

## Что изменилось

### AutoVPN: безопасная проверка резервного сервера

[PR #1252](https://github.com/VoltickVL/FreeNet-Router/pull/1252) объединён в `beta/v0.8.0`, 4/4 PR CI **terminal SUCCESS**: [Router](https://github.com/VoltickVL/FreeNet-Router/actions/runs/40670280674), [Production Browser](https://github.com/VoltickVL/FreeNet-Router/actions/runs/40670280620), [Routing](https://github.com/VoltickVL/FreeNet-Router/actions/runs/40670280533), [Config Studio](https://github.com/VoltickVL/FreeNet-Router/actions/runs/40670280557); MERGE SHA `8b2e1f79d42bcf59d35430f4b800fff84daf1994`.

**Исправление:** если AutoVPN обнаружил устойчиво медленный VPN, измерил альтернативы и первый измеренный Eligible-кандидат не прошёл свежую проверку сервисов/сегментов **до любых изменений Xray**, FreeNet делает одну ограниченную попытку с другим, ранее измеренным Eligible-кандидатом и другим endpoint. Резервный получает отдельный одноразовый selection snapshot с точной привязкой к измеренным данным, профилю, подписке и текущему состоянию. Сам fallback проходит стандартную проверку кандидата, повторную проверку текущего, writer admission, post-apply acceptance и rollback.

**Безопасность:** отказ финальной проверки не означает автоматическое переключение вслепую. При восстановившемся текущем VPN, отсутствующем или невалидном резервном, смене identity/subscription, parent timeout, небезопасном preflight, конфликте, неизвестном результате применения или rollback — STOP без следующей mutation. Сохраняются прежние anti-flap/cooldown и ограничения на частоту поиска. Увеличен ограниченный budget одного quality-цикла для проверки второго кандидата; бесконечных попыток нет.

**Проверки:** новые Go tests на два разных синтетических профиля: первый плохой/второй хороший; оба плохие; текущий восстановился; одноразовые snapshots, запрет повторного первого ID, изменение subscription fingerprint и запрет повторной попытки через тот же endpoint. CI также проходит browser, provider transaction и regression tests. Никакие реальные VPN-учётные данные не используются в тестах.

**Важные ограничения / runtime:** на Portable в браузере до выпуска — FreeNet beta.44, Xray v26.10.21, Instagram/Meta направлены через VPN; «94.6 Мбит/с» — общая измеренная скорость, **не проверка реального Instagram playback**. Зависание Instagram/ChatGPT требует дополнительных QoE-проверок на реальном пути. Во время текущей read-only проверки `/healthz=ok`, один `/versionz` запрос превысил 5 секунд, защищённый `/api/journal` вернул 401 без сессии. Это не доказывает неисправность конкретного VPN-сервера. Реальный AutoVPN switch и rollback на Portable в рамках релиза **не проверены**. Ранее на Portable отмечен `routing-gid-mismatch`, актуальная runtime inventory требует новой проверки; никакого обхода Xray identity gate.

Релиз не изменяет настройки работающих роутеров автоматически; установить только штатным FreeNet self-update с post-update acceptance. Связанные P1: #1225 (QoE/AutoVPN), #1227 (Xray identity), #1236 (transaction/rollback).
