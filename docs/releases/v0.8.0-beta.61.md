# FreeNet v0.8.0-beta.61

## Что изменилось

### Native DNS: защищённое согласование через Control Center

- [PR #1282](https://github.com/VoltickVL/FreeNet-Router/pull/1282): в «Настройки → Режим DNS» добавлена кнопка «Согласовать Native DNS» только при подтверждённом read-only состоянии `firmware`, `native-resolver-selection-replace`, выбранном Native DNS provider и отсутствии неопределённой filter-engine миграции.
- Перед изменением FreeNet повторно читает фактический план, сравнивает ожидаемую дельту и требует явное подтверждение.
- Применение выполняется только штатным транзакционным `network-profile/apply` с сохранением выбранного провайдера. После операции FreeNet требует нового read-only плана `active=true` и `dns-routing=native`. При ошибке или сомнительном результате: **STOP, без автоматической повторной попытки**.
- Защита от изменения неизвестной DNS-топологии, режима, провайдера, DNS owner или неподтверждённой сетевой операции.
- Дополнительные Go и Node contract tests: положительный и отрицательные сценарии, порядок plan→confirm→apply→plan и защита от сетевых изменений без подтверждения.

## Область изменений

Только отображение и применение существующей Native DNS recovery через браузер. XKeen, Xray binary, VPN credentials, подписка, routing policy и существующие настройки не меняются самим обновлением FreeNet. DNS меняется исключительно после отдельного подтверждённого действия в Control Center.
