# FreeNet Router v0.8.0-beta.21

## Что изменилось

- Обновлятор различает веб-панель и фоновые проверки FreeNet. При перезапуске он проверяет конкретный процесс панели и его порт; одноимённая задача по расписанию больше не служит подтверждением запуска панели.
- Файлы при откате восстанавливаются через подготовленный временный файл и атомарную замену. Обновлятор не пытается перезаписать исполняемый файл работающего процесса на месте.
- Проверки запуска и отката ограничены по времени и требуют ответа панели с ожидаемой версией. Причина отказа сохраняется в приватных материалах восстановления.
- Добавлена отдельная операция подтверждения уже восстановленного приложения. Она сверяет файлы с точным официальным выпуском, резервной копией, защищёнными настройками и текущим процессом панели. Исходная ошибка и доказательства сохраняются до подтверждения отката.

Обычное обновление по-прежнему запрещено, если предыдущий откат не подтверждён. Новая операция не устанавливает приложение, не переключает VPN и не удаляет блокировки. После подтверждения восстановления и завершения команды доступно штатное освобождение блокировки.

Установку этой версии следует выполнять проверенным обновлятором из этого выпуска: уже запущенный старый обновлятор не заменяет собственный алгоритм во время установки.
