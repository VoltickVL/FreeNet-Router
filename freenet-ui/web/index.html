Завершение настройки

Финальная проверка ничего не меняет. Она подтверждает подписку, выбранный Extra-профиль, Xray, dns-out и профиль интернет-провайдера. Только после успешной проверки станет доступно завершение настройки.

Быстрое переключение страны

«Обновить» повторно загружает текущий выбранный профиль. «Сменить сервер» выбирает другой endpoint в той же Extra-группе; если альтернативы нет, FreeNet ничего не меняет.
